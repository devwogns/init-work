# 에이전트 지침

작업 시작 시 `README.md`를 읽고 업무 범위·팀 규칙·문서 지도를 따른다.
현재 상태와 다음 행동은 `PROGRESS.md`에서 확인한다.

- 이 파일과 `CLAUDE.md`는 이 프로젝트의 공식 에이전트 지침이며 다른 공통 문서와 함께 커밋한다.
- 팀 공통 규칙과 업무 판단은 `README.md`·`decisions.md`에 기록한다.
- 이 프로젝트에서 확인된 셸·인코딩·도구 사용 지침만 이 파일에 추가한다. 다른 작업의 환경·개인 설정을 복사하지 않는다.
- 개인 환경에만 필요한 지침은 이 파일에 넣지 않고 커밋하지 않는 로컬 설정에 둔다.
